A turtle wow addon that will check what spells are on your action bars and if there is a higher rank spell available in your spell book notify you.

Place .lua and .toc file in Interface\Addons\AutoSpellRanker

type /asr in chat to see what spells if any need to be replaced with a higher level spell.
